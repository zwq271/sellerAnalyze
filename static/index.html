市场：美国是检索目标，免费搜索不能保证结果全部属于美国销售市场。未知市场会明确标注。

带货与商品：有明确带货标记或商品 ID 时才确认；文案提及 TikTok Shop 只算线索。没有商品信息时留空。

销量与销售额：网页未提供时留空，不从播放量推测。已有导入数据可以继续保留。

登录与下载：使用独立浏览器会话。登录和验证码由你手动完成，会话仅保存在本机；下载会尝试复用该会话。
